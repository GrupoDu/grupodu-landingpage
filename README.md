# Landing page Grupo Du
## Descrição
Este repositório abriga a landing page institucional da empresa GrupoDu.
A página foi construída com foco em apresentação da marca, serviço de contato e captação de leads, utilizando tecnologia moderna (TypeScript, SCSS) para garantir desempenho, manutenção e escalabilidade.

## Guia de instalação
Siga os passos abaixo para clonar, configurar e rodar o projeto localmente.

#### Pré requisitos
- Node.js (versão compatível conforme package.json)
- NPM ou Yarn
- Um terminal de linha de comando

#### Passos
1. Clone o repositório:
```bash
git clone https://github.com/GrupoDu/grupodu-landingpage.git  
```
2. Entre no diretório do projeto:
```bash
cd grupodu-landingpage  
```
3. Instale as dependências:
```bash
npm install
```
4. Execute o ambiente de desenvolvimento:
```bash
npm run dev
```
Isso iniciará o servidor local e você poderá visualizar a landing page no seu navegador (normalmente em http://localhost:3000 ou porta configurada).
5. Para build de produção:
```bash
npm run build
```
Após o build, para testar localmante:
```bash
npm run start
```
